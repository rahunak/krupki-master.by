# План: Telegram-уведомления о заказах

**Дата:** 2026-08-21
**Статус:** Планирование

---

## 📋 Задача

Добавить отправку уведомлений в Telegram-бот при создании нового заказа через форму OrderForm.tsx. Бот должен быть доступен только для определённого списка администраторов.

---

## ✅ Требования

1. **Уведомление в Telegram при новом заказе**
   - Отправка происходит после успешной записи в Supabase
   - Сообщение содержит все данные заказа (имя, телефон, город, описание, способ связи)
   
2. **Белый список администраторов**
   - Только указанные Telegram ID могут получать уведомления
   - Список хранится в env-переменной `ADMIN_WHITELIST`
   
3. **Безопасность**
   - Bot Token хранится в `.env.local` (не коммитится)
   - API route защищён от прямого вызова извне

## ⚠️ Важные моменты

1. **Белый список** — сначала проверяем, что chat_id отправителя в списке администраторов
2. **Fallback** — если Telegram API недоступен, заказ всё равно сохраняется в Supabase
3. **Логирование** — записывать ошибки отправки, но не блокировать пользователя
4. **Rate limiting** — Telegram API имеет лимиты (30 сообщений/секунду)
