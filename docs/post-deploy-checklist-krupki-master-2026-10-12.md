## 1. 🤖 Уведомить поисковики (IndexNow) — сразу после деплоя

```bash
curl -s -X POST https://krupki-master.by/api/indexnow -d '{}' | head -c 300
```

- Отправляет весь sitemap (11 URL) в Яндекс/Bing/Seznam через api.indexnow.org.
- Ожидаемый ответ: `{"ok":true,"status":202,...}`.
- Ключ: `8be2a9a1aced14dc3c8d1d3b65e50aa0`, файл подтверждения —
  `https://krupki-master.by/indexnow-key.txt` (уже в `public/`).
- Можно дёргать и точечно: `-d '{"urls":["https://krupki-master.by/doski/menazhnitsy/"]}'`.

## 2. 👆 Google Search Console — запросить индексацию вручную

- Проверить, что доступ сервис-аккаунта google-seo-mcp **по-прежнему 403** —
  если да, выдать доступ: GSC → Настройки → Пользователи → добавить email
  (email смотреть в кабинете Vercel/GCP).
- GSC → Проверка URL → по очереди для 11 URL из sitemap → «Запросить индексацию».
  Priority: `/doski/`, `/doski/razdelochnye/`, `/doski/menazhnitsy/`,
  `/doski/podarochnye_nabory/`, потом блог.
- Через день-два проверить «Покрытие» — страницы должны быть «Проиндексировано».

## 3. 👆 Яндекс.Вебмастер

- Добавить сайт (если ещё нет): webmaster.yandex.ru → «+» → krupki-master.by.
- Верификация тем же IndexNow-ключом: файл `indexnow-key.txt` уже в public —
  в Вебмастере выбрать способ верификации «HTML-файл» и загрузить любой файл
  с этим именем (или через Meta-тег).
- Отправить sitemap.xml на индексирование.
- Диагностика → «Страницы в поиске» — через неделю проверить охват.

## 4. 🤖 Проверка разметки на проде

После деплоя выполнить:

```bash
# Product + FAQPage в HTML
curl -sL https://krupki-master.by/doski/razdelochnye/ | grep -c '"@type":"Question"'
# ожидается: 5
curl -sL https://krupki-master.by/doski/razdelochnye/ | grep -o '"image":\[[^]]*' | head -c 150
# ожидается: массив с image/*.avif

# Rich Results Test (Google)
# https://search.google.com/test/rich-results?url=https%3A%2F%2Fkrupki-master.by%2Fdoski%2Frazdelochnye%2F
```

Если на проде `Question` не 5 — вероятно кеш CDN (Cache-Control в next.config.ts
стоит s-maxage=86400, сутки) → сбросить кеш хостинга или подождать.
