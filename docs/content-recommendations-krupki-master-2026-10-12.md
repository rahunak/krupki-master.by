## 2. Реальный спрос (Google Suggest, geo=BY, live)

Группировка подсказок по интентам:

### Кластер «разделочная доска» — самый объёмный, покупки
- `разделочная доска из дуба` — прямо наш товар
- `разделочная доска из дуба купить минск` — конверсионный, прямо наш товар
- `разделочная доска из дуба своими руками` — информационный, тема контента
- `разделочная доска из натурального дерева`, `…из дерева` — широкие
- `разделочная доска купить минск`, `…какая лучше` — интент выбора
- `разделочная доска купить на ozon` — конкуренты на маркетплейсах
- **Пробел:** `торцевая разделочная доска купить [минск]` — подсказка есть,
  товара на сайте нет. Торцевая доска (end grain) — премиум-сегмент
  с высокой ценой и реальным спросом. Если мастер умеет — стоит добавить SKU.

### Кластер «менажница» — покупки + вопросы
- `менажница деревянная купить минск` и `менажница купить минск` — конверсионные
- `менажница это` / `менажница для чего` / `менажница фото` — информационный
  спрос есть, целевых страниц нет → статья блога «Что такое менажница
  и как её использовать» с перелинковкой на `/doski/menazhnitsy/`
- `менажница ами мебель`, `…фикс прайс` — конкуренты-бренды, перехватываются
  только отзывами и ценой, не SEO

### Кластер «доска из дуба» — строительный + кухонный
- `доска из дуба купить`, `…цена`, `…40х100`, `…обрезная` — стройматериал, не наш
- `доска из дуба для кухни` — наш, целевой

### Кластеры «доска для подачи / для сервировки» — альтернативная семантика
Менажницы ищут и этими словами (`подача блюд / мяса / стейка / сыра / закусок`,
`сервировка стола / сыра / мяса`).
**Действие:** на странице `/doski/menazhnitsy/` в description и тексте
(не в H1) добавить фразы «сервировочная доска для подачи блюд / сыра / мяса»
— захват без новых страниц.

### Кластер «подарочные наборы» — спрос слабее ожиданий
- `подарочный набор доска` — **0 подсказок**
- Реальный спрос идёт через `подарок на новоселье`, `подарок повару`.
- **Действие:** переписать H1/текст `/doski/podarochnye_nabory/` под
  «подарок на новоселье / подарок гурману», состав «доска + соусники»
  оставить в тексте.

## 4. Берёза — стоит ли добавлять раздел? НЕТ (пока)

Проверено по Google Suggest geo=BY (в т.ч. с обеими формами: е/ё):
- `разделочная доска из берёзы / березы` — 0 подсказок
- `берёзовая доска / березовая` — 0 подсказок
- `доска из берёзы` — 0 подсказок

Для сравнения: `разделочная доска из дуба` — 3+ подсказки,
`менажница деревянная` — 5 подсказок. Спрос на берёзовые кухонные изделия
в BY-поиске не виден вообще.

Аргументы против:
1. У дуба сильная кулинарная репутация («дуб не тупит ножи»), у берёзы — нет.
2. Берёза мягче — для кухонных досок используется реже, спрос подтверждает.
3. Сайт маленький (10 страниц): новый раздел под нулевой спрос разбавляет
   сайт перед домом, где важнее углубить дубовый кластер и кластер подачи.
4. Финансово: время мастера выгоднее потратить на торцевые доски
   (подтверждённый премиум-спрос), чем на берёзовую линейку.

**Когда вернуться к берёзе:** если после индексации GSC покажет показы
вопросов про берёзу в кластере «какую доску выбрать» — добавить абзац
«также делаем из берёзы на заказ» на `/doski/razdelochnye/`. Полноценный
раздел — только после появления подсказок в Suggest.
