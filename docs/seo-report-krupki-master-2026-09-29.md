## 4. Слабые места сайта

1. **Одна страница на весь сайт** — продвигаться по 6+ кластерам запросов нечем: под
   каждую услугу нужна своя целевая страница со своей семантикой.
2. **Контента мало** (2.4K символов) — конкуренты (SAM-Мастерс, Chipik) дают больше текста и FAQ.
3. **Нет блога/статей** — информационный трафик («как заточить цепь», «угол заточки топора»)
   теряется, внутреннего веса для лендинга не наращивается.
4. **Форма**: лишние поля (город, описание) снижают конверсию; канал связи не выбирается;
   уведомления уходят только в личку админам, а не в общий канал.
5. **GSC-доступа нет** у сервис-аккаунта — нет данных по запросам/позициям.
